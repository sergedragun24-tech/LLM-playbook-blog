# Протокол регистра: навык corporate-tech-register

Принято 01.10.2026 по итогам работы над статьёй «GPU-серверы для бизнеса и 6 сценариев».

## Что где лежит

**Навык `corporate-tech-register`, уровень аккаунта.** Регистр, лексика, пять формул
построения фразы, эталоны по восьми слотам, три правила логики, структура, ритм,
семь вопросов самопроверки. Работает во всех проектах и в обычных чатах,
подключается по совпадению описания с задачей.

**Инструкции и каноны этого проекта.** Канон фактов компании, продуктовые заявления,
пайплайн трёх чатов, линтер, регистр эталонных статей блога. В другие проекты не
переносится.

Разделение сделано намеренно: регистр универсален для любого провайдерского блога,
фактура нет.

## Протокол прогона

1. Первой строкой любого прогона писать «регистр загружен» или «регистра нет».
2. Черновик и правку текста не начинать, пока навык не загружен.
3. Если навык не подхватился сам, загрузить принудительно, затем писать.
4. Самопроверку по семи вопросам прогонять после каждого раздела, до перехода к
   следующему, а не по готовой статье.

Автоматическое срабатывание не стопроцентное. На приёмке и правке статьи навык
подхватывается почти наверняка, на коротком запросе вроде «перепиши этот абзац»
может не сработать. Протокол закрывает этот разрыв.

## Как редактор может проверить

- Вызов навыка виден в ленте чата отдельным шагом до начала письма.
- По запросу «подтверди регистр» выводятся дословно формула определения термина,
  формула лида и первые позиции списка запрещённых глаголов.
- Принудительный вызов: «применяй corporate-tech-register» в начале задачи.

## Что осталось открытым

- Пороги по разбросу длин предложений из навыка убраны как неизмеренные. Вернуть
  после прогона линтера по опубликованным статьям блога.
- Линтер переделывается: пороги ритма, метрика короткого зачина (сейчас считает
  отказом абзацы из двух предложений равной длины), словарь бытовой лексики.
- Отменённые правила канона читаемости, которые надо снять в самом каноне:
  запрет на «железо», сплошной запрет на отглагольные существительные, запрет на
  «стоит» в значении рекомендации, учёт повтора связок в соседних абзацах.
